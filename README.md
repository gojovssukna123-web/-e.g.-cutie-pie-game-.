# Arrow Heart Game

1. Put `index.html` into the GitHub Pages repository named `arrow-heart-game`.
2. Enable GitHub Pages for the repository.
3. The QR code in `arrow_heart_qr.png` points to:
   https://shnak962715-web.github.io/arrow-heart-game/
4. Scan the QR after the page is published.

The game is a mobile-friendly tap-to-shoot heart target game inspired by the supplied video.
